# Attribution

GlassGamePanel free Wings installer  
Glasshouse Holding Group / GlassHosting / GlassGamePanel

This directory is a Glasshouse-branded installer for an **operator-owned**
(DIY) Wings node. It does not enroll you on a GlassHosting production panel,
and it is not a WHMCS module.

The wrapper scripts, unit template, brand banner, refuse lists, and docs in
this directory are part of the GlassGamePanel free package. Support is the
documentation in `README.md` (Discussions category `free-ggp`, Issues label
`free-ggp`, or sales@glasshosting.com).

The Wings daemon itself is an upstream **Pterodactyl Wings** binary. Wings is a
separate work published by the Pterodactyl project. Operators who install that
binary must comply with the upstream project's license (MIT at the time this
package was assembled). This wrapper does not relicense the upstream binary and
does not ship GlassHosting production credentials.

Artifact name prefix: `glassgamepanel-wings-free-`.

Verify `SHA256SUMS` before you run the installer.
